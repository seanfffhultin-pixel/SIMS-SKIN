Chrome, Edge or Firefox

  1. Install Tampermonkey from its official browser-store link.
  2. On Chrome/Edge, open the extension’s details and enable Allow User Scripts if shown. Tampermonkey’s instructions.
  3. Click Copy script above.
  4. Open Tampermonkey → Create a new script. Replace the starter text with the copied script, then save.
  5. Open SIMS Student and reload it. Allow the extension to run on SIMS if prompted.

Safari: skin and homework ticks

  1. Install Userscripts, then enable it in Safari → Settings → Extensions.
  2. Open the Userscripts app and choose its scripts folder. Save the downloaded shsb-sims.user.js into that folder.
  3. Allow Userscripts access to www.sims-student.co.uk, then reload SIMS.
  4. If you previously installed the CSS-only skin, set Safari → Settings → Advanced → Style sheet to None Selected. The script includes the latest stylesheet.

Userscripts setup help

Your personal homework list

Use Mark done to remove a task from To do. Open the Done section to find it again. These sections filter the assignments SIMS has loaded in the current list; the dashboard only contains SIMS’s preview items. Untick it in Done to return it to To do. These ticks persist in this browser and are separated by school, student and assignment ID.

They do not hand in work or change SIMS’s overdue status. Use SIMS’s Submit for Marking when required. Ticks do not sync between browsers and are lost if you clear SIMS site data.

If SIMS cannot expose an assignment’s ID, its tick is disabled rather than saved against the wrong homework.

Safari: appearance only, without an extension

Download the CSS-only skin, save it somewhere permanent and select it in Safari → Settings → Advanced → Style sheet → Other…. This option cannot add homework ticks.

Update your phone to v0.5.0

Download the latest script on your Mac and AirDrop it to your phone, or transfer it using iCloud Drive. In Files, replace shsb-sims.user.js in the folder selected by Userscripts. Keep just one copy enabled, then reload SIMS in Safari. Your saved homework ticks are preserved.

Undo or update

Disable the script in your extension and reload SIMS to restore the original appearance. To update, replace the saved script with the latest download. You can close this installer and stop the local app after installation.

Styles cover the dashboard, homework, messages, calendar, timetable, activities, attendance, assessment, conduct, reports and school details. External services opened by SIMS keep their own appearance.

The script uses information already loaded by SIMS and stores only assignment identifiers and completion flags locally. It makes no network requests and does not read your login tokens or password.

Built against SIMS’s public templates and tested with example pages. Live account verification in each browser is still needed. If a page looks wrong, disable the script and share a screenshot.
